# 90Minute Studio website

## Files
- `index.html` — responsive bilingual studio website (Turkish / English)
- `assets/90minute-studio-logo.png` — supplied 90Minute Studio logo

## Publish with GitHub Pages
Upload `index.html` and the `assets` folder to the root of the `samettopcu.github.io` repository.
Keep your existing `app-ads.txt` file in the repository root; do not replace or delete it.

The website uses only local assets and browser-native HTML/CSS/JavaScript. No build step is required.
